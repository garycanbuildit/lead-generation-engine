# Agent Scaffold

This repository follows the **DOE loop** (Directive → Observation → Experiment) architecture as defined in `agents.md`.

## Structure
- `directives/`: SOP-style instructions (Markdown)
- `execution/`: Deterministic Python scripts
- `.tmp/`: Disposable temporary files
- `.env`: API keys and environment variables

Refer to `agents.md` for full operating instructions.
